# 🚀 DevLab OS

> The Operating System for Modern Software Engineers.

DevLab OS is an all-in-one engineering workspace built with the MEAN Stack. It combines project management, architecture visualization, documentation, collaboration, analytics, and AI-assisted development into a single platform.

## 🛠️ Tech Stack

### Frontend
- Angular

### Backend
- Node.js
- Express.js

### Database
- MongoDB
